## 修复内容

### 1. ContextManager 修复（核心 Bug）

**问题：** auto-compact 无效，压缩后仍然是 140K+ tokens
**根因：** `_build_post_compact_messages` 保留了最后 10 条消息，包含大段 L0 读取结果
**修复：**
- `_keep_count` 从 10 降为 3
- `_extract_compressable_content` 截取长度从 1000/500 降为 500/300
- 增加 `_build_ultra_compact_messages` 兜底（只保留 system + user + summary）
- 验证 auto-compact 后 token 数是否真的减少

**验证结果：**
- 压缩前：~140K tokens → 压缩后：~1.4K tokens ✅（压缩率 99%）
- 压缩后上下文保持可控：1.4K → 5K → 7K（正常增长）

### 2. 前端上下文进度展示

**新增：**
- 上下文占用百分比进度条（绿/黄/红三色）
- auto-compact/microcompact 触发时显示提示文字
