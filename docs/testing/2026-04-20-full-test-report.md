## 🔴 P0 问题（阻塞使用）

### 1. WebSocket 连接失败 ❌

**问题描述:**
- 对话页面显示 "未检测到 WebSocket 连接"
- 发送按钮始终 disabled
- 无法进行对话

**测试截图:** `screenshot-1776694572998.png`

**影响:** 对话功能完全不可用

**可能原因:**
1. 后端 WebSocket 端点未正确实现
2. 前端 WebSocket 客户端连接逻辑有误
3. CORS 配置问题

**建议:**
1. 检查 `backend/app/api/websocket.py` 是否存在
2. 检查 `frontend/src/api/websocket.ts` 连接代码
3. 在浏览器 DevTools Network 面板查看 WebSocket 连接详情

---

### 2. 图谱页面无内容显示 ❌

**问题描述:**
- 选择 KB full_kb（已完成编译，有 2 个文档）
- 点击刷新后，页面空白，无图谱显示
- 只有网格背景，无节点和边

**测试截图:** `screenshot-1776694674736.png`

**影响:** 图谱功能不可用

**可能原因:**
1. 前端图谱渲染组件未实现
2. 图谱数据 API 返回为空
3. D3.js 等图谱库未正确加载

**建议:**
1. 检查 `frontend/src/components/graph/GraphView.tsx`
2. 调用 API `/api/graph/{kb_id}` 验证返回数据
3. 检查前端控制台错误

---

### 3. Wiki 页面无内容显示 ⚠️

**问题描述:**
- Wiki 页面有"实体"和"时间线"按钮
- 点击后无任何内容显示

**测试截图:** `screenshot-1776694208590.png`

**影响:** Wiki 功能部分可用

**可能原因:**
1. 实体/时间线数据为空

**建议:**
