## 🧪 前端测试方法

> **重要：** OpenClaw 内置浏览器被 policy 拦截，无法直接测试前端。使用 `agent-browser` CLI 绕过限制。

### 工具准备

```bash
# 检查 agent-browser 是否可用
agent-browser --version
# 输出: agent-browser 0.20.14
```

### 基础操作命令

```bash
# 1. 打开页面
agent-browser open "http://127.0.0.1:5173/"

# 2. 查看页面元素（交互式）
agent-browser snapshot -i

# 3. 截图
agent-browser screenshot
# 截图保存在: C:\Users\openlab\.agent-browser\tmp\screenshots\

# 4. 点击元素（使用 @ref 引用）
agent-browser click "@e8"

# 5. 填写输入框
agent-browser fill "@e4" "输入内容"

# 6. 等待（毫秒）
agent-browser wait 2000

# 7. 滚动页面
agent-browser scroll down 500

# 8. 获取元素文本
agent-browser get text @e1

# 9. 关闭浏览器
agent-browser close
```

### 测试流程示例

```bash
# 打开前端
agent-browser open "http://127.0.0.1:5173/"

# 查看首页元素
agent-browser snapshot -i
# 输出:
# - heading "SDA" [level=2, ref=e1]
# - link "🏠 首页" [ref=e3]
# - link "📁 知识库" [ref=e4]
# ...

# 点击设置页面
agent-browser click "@e8"  # 设置链接的 ref

# 等待页面加载
agent-browser wait 2000

# 查看设置页面元素
agent-browser snapshot -i

# 截图保存
agent-browser screenshot

# 关闭
agent-browser close
```

### 注意事项

1. **PowerShell 多命令执行：** PowerShell 不支持 `&&` 链接命令，需要分开执行
2. **Ref 会变化：** 每次页面刷新后 ref 会重新编号，需要重新 snapshot
3. **等待加载：** 页面跳转后建议 wait 等待加载完成
4. **截图路径：** 截图保存在 `C:\Users\openlab\.agent-browser\tmp\screenshots\`
